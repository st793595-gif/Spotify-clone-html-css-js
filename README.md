# Spotify Clone 🎵

A Spotify-inspired music player interface built using HTML, CSS, and JavaScript as a web development project.

## Features
- Spotify-inspired user interface
- Music library with song and album cards
- Interactive music playback controls
- Responsive layout for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript 

## Project Preview
This project recreates the look and basic music-playing experience of Spotify for learning and practice.
